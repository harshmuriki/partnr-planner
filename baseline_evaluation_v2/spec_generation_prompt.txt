## Variant matrix (20 per task)
Columns combine Internal Robot Memory with one non-default external axis (others default).
ROOM and CAND exist only with Accurate memory.

ACCURATE (ACC): ACC-BASE, ACC-SUB, ACC-ABS, ACC-CON, ACC-DIS, ACC-AMB, ACC-ROOM, ACC-CAND
INCOMPLETE (INC): INC-BASE, INC-SUB, INC-ABS, INC-CON, INC-DIS, INC-AMB
OUTDATED (OUT): OUT-BASE, OUT-SUB, OUT-ABS, OUT-CON, OUT-DIS, OUT-AMB

Meaning of the external axis (from New Un):
- BASE: Target exists on a surface; no distractors; fully specified instruction.
- SUB: Requested target missing; suitable substitute exists and is correctly represented when memory is Accurate. Incomplete: substitute missing from memory. Outdated: memory still has the missing target at a stale location, not the substitute.
- ABS: Target and substitutes unavailable. Accurate memory knows that. Incomplete: memory lacks enough info (should give up). Outdated: memory falsely suggests a suitable object exists.
- CON: Selected uncertainty-target object(s) start inside a closed receptacle. Accurate memory knows containment. Incomplete: containment/object missing from memory. Outdated: memory has an old on-surface location.
- DIS: Spreadsheet distractors present near targets. Accurate: memory has them. Incomplete: target and/or distractors missing. Outdated: stale info about target/distractors.
- AMB: Use spreadsheet underspecified instruction. Accurate: world fully known. Incomplete: also missing env info. Outdated: also stale env info.
- ROOM: Robot/instruction knows the room but not exact furniture (Accurate only).
- CAND: Robot/instruction knows only candidate rooms (Accurate only).
